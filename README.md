# Ремонт Шишкина — мебель и планировки

Квартира в Ижевске под сдачу, планировка Финал 2. Два цветовых варианта: **Белый** и **Шалфей**.

## Сайт (`docs/`)

- `index.html` — визуализации (главная); `planirovki.html` — листы планировок; `podbor.html` — общая страница подбора с выбором варианта и итогами.
- `razmery.html` — таблица размеров и пределов по комнатам, данные в `data/razmery.json`.
- `prihozhaya`, `kuhnya`, `stolovaya`, `gostinaya`, `spalnya`, `rabochee-mesto` `.html` — по странице на комнату.
- Вариант выбирается переключателем сверху и сохраняется при переходах между комнатами.

Открыть: `python -m http.server -d docs`, либо GitHub Pages из папки `docs/`.

## Как поменять позицию

1. В `data/mebel.json` найти комнату и позицию. `variant`: `all`, `belyj` или `shalfej`.
2. `main` — основной товар; в `extras` роль `addon` входит в сумму, `alt` — запасной.
3. `python3 tools/build.py` — пересобрать `docs/`.

Прочее: `img/` — фото товаров, `plans/` — исходники планировок, `planirovki/` — листы планировок (PNG и PDF, попадают на страницу «Планировки»), `vizualizacii/` — промпты.

Визуализации: оригиналы в `vizualizacii/render/` (ранние версии в `arhiv/`), на сайте страница «Визуализации» и галерея на каждой комнате.
